# 航空航天 AI Agent

> 行业分类: 航空航天 (Aerospace) | 更新时间: 2026-05-28

## 概述

AI Agent 在航空航天领域的应用涵盖飞行器设计、任务规划、飞行控制、卫星运营和空域管理等方向。该领域对安全性和可靠性的极高要求，使得 Agent 系统需要具备严格的验证与确认 (V&V) 能力。自主飞行和无人机集群管理是当前最活跃的研究方向之一。

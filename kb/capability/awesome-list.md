# Awesome List

> 能力分类: Awesome Lists | 更新时间: 2026-06-12

## 概述

Awesome List 是 GitHub 上独特的知识组织形式——由社区维护的、结构化的精选资源列表。在 AI/Agent 领域，Awesome List 是快速了解某个技术方向的最佳入口，通常由领域专家持续维护，收录该方向最优质的工具、论文、教程和资源。

Awesome List 的价值在于"策展"（Curation）：在信息爆炸的时代，它们帮助开发者过滤噪音，直达最有价值的项目。一个高质量的 Awesome List 通常包含：分类整理的项目列表、简要描述、Stars 数、活跃度指标、以及推荐理由。2026 年，AI 领域的 Awesome List 已经从简单的链接集合进化为包含评估基准、对比矩阵和入门指南的知识库。

## 快速上手

### 浏览 Awesome List
```bash
# 克隆感兴趣的列表
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
# 查看 README 中的分类和推荐项目
cat README.md
```

### 贡献到 Awesome List
```bash
# 1. Fork 仓库
# 2. 添加你的项目到对应分类
# 3. 确保包含：项目名称、链接、简要描述
# 4. 提交 PR
```

### 创建自己的 Awesome List
```markdown
# Awesome [Topic]

> 一句话描述

## 分类一
- [项目名](链接) - 简要描述
- [项目名](链接) - 简要描述

## 分类二
- [项目名](链接) - 简要描述

## 贡献指南
欢迎提交 PR！
```

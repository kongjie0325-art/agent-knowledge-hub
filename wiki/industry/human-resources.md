## 核心发现

- **[mergisi/awesome-openclaw-agents](https://github.com/mergisi/awesome-openclaw-agents)** (-⭐): 162 个生产就绪 AI Agent 模板，含 HR 分类：Onboarding（新员工引导）、Benefits Advisor（福利顾问）、Compliance Checker（合规检查）等
- **[ruvnet/agentic-employment](https://github.com/ruvnet/agentic-employment)** (-⭐): 首个通过自主 Agent 自动化和增强雇佣流程的平台，覆盖招聘、入职、员工管理等 HR 核心场景
- **[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)** (80k⭐): 51 个 AI 专家 Agent，含支持部门（Analytics、Finance、Legal）Agent，可复用于 HR 数据分析和合规场景
- **[ashishpatel26/500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)** (30.4k⭐): 500+ AI Agent 跨行业项目精选，含 HR 招聘、培训、绩效等多个 HR 子领域开源项目
- **[ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills)** (61.7k⭐): Claude Skills 精选列表，含 HR 相关技能：招聘筛选、员工入职、绩效评估等
- **[jobright-ai/2026-HR-New-Grad](https://github.com/jobright-ai/2026-HR-New-Grad)** (-⭐): 2026 年 HR 新毕业生职位每日更新，AI 驱动的招聘资源集合
- **[langchain-ai/langchain](https://github.com/langchain-ai/langchain)** (138k⭐): 构建 HR AI Agent 的基础框架，支持 RAG 驱动的政策问答、多步骤招聘流程编排、员工数据分析
- **[microsoft/autogen](https://github.com/microsoft/autogen)** (58k⭐): 多 Agent 对话框架，适合构建 HR 团队协作 Agent（招聘官、HRBP、培训专员）
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** (52k⭐): 多 Agent 编排框架，适合构建 HR 工作流团队（简历筛选员、面试官、入职协调员）
- **[langgenius/dify](https://github.com/langgenius/dify)** (142k⭐): 低代码 Agent 构建平台，HR 团队可快速搭建员工服务台、招聘助手等 Agent 工作流
- **[open-webui/open-webui](https://github.com/open-webui/open-webui)** (138k⭐): 自托管 AI Web UI，HR 团队用于本地部署员工自助服务和 HR 助手工具
- **[lobehub/lobe-chat](https://github.com/lobehub/lobe-chat)** (77k⭐): 开源 ChatGPT UI，HR 团队用于构建员工内部问答和 HR 政策查询助手
- **[FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise)** (53k⭐): 拖放式 LLM 流程构建器，HR 团队无需编码即可构建招聘流程和员工服务 Agent
- **[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)** (170k⭐): Hermes Agent 框架，支持 HR 场景中的自定义 Agent 开发和部署
- **[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)** (23.1k⭐): Agent Skills 精选列表，含 HR 相关技能模板（招聘、入职、绩效）

## 实践指南

### 招聘管理
- 简历解析与筛选
- 候选人匹配与排名
- 面试安排与协调
- 候选人沟通自动化
- Offer 管理
### 员工入职
- 入职流程自动化（文档签署、设备申领、账号开通）
- 新员工引导（组织架构、团队介绍、系统培训）
- 入职任务跟踪
- 30/60/90 天计划生成
### 培训与发展
- 个性化学习路径推荐
- 培训内容生成
- 技能差距分析
- 学习进度跟踪
### 绩效管理
- OKR/KPI 追踪
- 360° 反馈收集与分析
- 绩效报告生成
- 目标设定辅助
### 员工服务台
- HR 政策 FAQ 自动回答
- 休假申请与审批
- 薪酬福利查询
- IT 工单转接
### 合规与审计
- 劳动法合规检查
- 员工数据隐私保护
- 审计追踪与报告
- 多元化与包容性分析

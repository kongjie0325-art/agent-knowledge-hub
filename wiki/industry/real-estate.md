# 房地产 AI Agent

> Sources: kb/industry/real-estate.md; 2026-06-12
> Raw: [real-estate](../../raw/industry/real-estate.md)

## 概述

> 行业分类: 房地产 (Real Estate / PropTech) | 更新时间: 2026-05-28

## 关键概念

- 1. 房产检测与评估
- 基于计算机视觉的房屋损伤/异常检测
- 自动化房产检测报告生成
- 2. 智能搜索与推荐
- 自然语言驱动的房产搜索
- 个性化房源推荐
- 3. 投资分析与估值
- ML 驱动的房价预测
- 多 Agent 投资分析系统
- 4. 智能客服与合规
- 7×24 小时房产咨询聊天机器人
- 合规性保障
- 5. 物业管理
- AI 驱动的物业维护工单管理
- 租户沟通自动化

## 核心发现

- **[langgenius/dify](https://github.com/langgenius/dify)** (142k⭐): 生产级 Agentic 工作流平台，支持 RAG、多模型Provider，广泛用于构建房产搜索和分析 Agent
- **[langchain-ai/langchain](https://github.com/langchain-ai/langchain)** (138k⭐): 最流行的 LLM Agent 开发框架，大量房产 Agent 项目基于此构建
- **[open-webui/open-webui](https://github.com/open-webui/open-webui)** (138k⭐): 开源 AI 交互界面平台，可作为房产 Agent 的前端交互层
- **[anthropics/claude-code](https://github.com/anthropics/claude-code)** (127k⭐): Anthropic 的 AI 编码 Agent，支持 Skills 插件，ahacker-1/cre-agent-skills 等房地产 Skills 基于此运行
- **[Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)** (111k⭐): 100+ AI Agent & RAG 应用模板，包含多个房产 Agent 参考实现
- **[lobehub/lobe-chat](https://github.com/lobehub/lobe-chat)** (77k⭐): 开源多模型聊天框架，支持 Agent 插件，可用于构建房产咨询助手
- **[microsoft/autogen](https://github.com/microsoft/autogen)** (58k⭐): 微软多 Agent 协作框架，Azure-Samples 房产投资分析方案基于此
- **[FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise)** (53k⭐): 低代码 Agent 构建平台，适合快速搭建房产搜索 Agent
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** (52k⭐): 多 Agent 编排框架，Arindam200/awesome-ai-apps 中的 Car Finder Agent 使用
- **[ashishpatel26/500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)** (30k⭐): 500+ AI Agent 跨行业应用案例合集，含房地产方向
- **[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)** (23k⭐): 精选 Agent Skills 集合，包含房地产领域 Skills
- **[aws-samples/sample-amazon-bedrock-property-inspection-agent](https://github.com/aws-samples/sample-amazon-bedrock-property-inspection-agent)** (-⭐): AWS 官方示例：基于 Amazon Bedrock 的房产异常检测 Agent，支持对话式深度分析
- **[brightdata/real-estate-ai-agent](https://github.com/brightdata/real-estate-ai-agent)** (-⭐): 基于 Bright Data MCP + Nebius Qwen LLM 的房产数据智能提取系统，输出结构化 JSON
- **[zillow/compliant-real-estate-chatbot](https://github.com/zillow/compliant-real-estate-chatbot)** (-⭐): Zillow 官方开源：基于 Llama3 8B 微调的合规房产聊天机器人，防止歧视性引导
- **[Josephrp/EasyRealEstate](https://github.com/Josephrp/EasyRealEstate)** (-⭐): 多 Agent 房产分析系统，专为意大利房产市场设计，支持编码辅助分析

## 实践指南

### 1. 房产检测与评估
- 基于计算机视觉的房屋损伤/异常检测
- 自动化房产检测报告生成
- 多模态（图像 + 文本）房产状况评估
### 2. 智能搜索与推荐
- 自然语言驱动的房产搜索
- 个性化房源推荐（基于用户偏好、预算、位置）
- 对话式房产导购助手
### 3. 投资分析与估值
- ML 驱动的房价预测（Zestimate 等）
- 多 Agent 投资分析系统
- 商业地产（CRE）承销与尽职调查
### 4. 智能客服与合规
- 7×24 小时房产咨询聊天机器人
- 合规性保障（反歧视、反引导）
- 租户/房东法律问题解答
### 5. 物业管理
- AI 驱动的物业维护工单管理
- 租户沟通自动化
- 房产数据提取与结构化
### 6. 数据抓取与市场分析
- 房产公开数据智能抓取（MCP + 爬虫）
- 市场趋势分析与报告生成
- 竞品定价与社区分析

## 核心发现

- **[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)** (80k⭐): 完整的 AI Agency：51 个 AI 专家 Agent，含 8 个营销专家（增长、内容、社交媒体、TikTok、Instagram、Reddit 等），每个 Agent 有独特性格和完整工作流
- **[ashishpatel26/500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)** (30.4k⭐): 500+ AI Agent 跨行业项目精选，含内容营销、广告投放、社媒运营等多个营销子领域
- **[wshobson/agents](https://github.com/wshobson/agents)** (-⭐): 多平台 Agent 插件市场（155 技能），含 content-marketing 插件，覆盖 AI 内容创作、SEO、社媒策略、邮件营销、内容分发、数据分析
- **[caramaschiHG/awesome-ai-agents-2026](https://github.com/caramaschiHG/awesome-ai-agents-2026)** (974⭐): 2026 年最全面的 AI Agent 列表（300+ 资源，20+ 分类），含营销 Agent 和增长黑客专题分类
- **[ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills)** (61.7k⭐): Claude Skills 精选列表，含多个营销技能：SEO 优化、内容创作、社媒管理、邮件自动化等
- **[mallahyari/ml-practical-usecases](https://github.com/mallahyari/ml-practical-usecases)** (-⭐): ML 实战用例集合，含营销领域的客户细分、流失预测、推荐系统等案例
- **[langchain-ai/langchain](https://github.com/langchain-ai/langchain)** (138k⭐): 构建营销 AI Agent 的基础框架，支持 RAG 驱动的内容生成、工具调用型广告 Agent、多渠道营销编排
- **[microsoft/autogen](https://github.com/microsoft/autogen)** (58k⭐): 多 Agent 对话框架，适合构建营销团队协作 Agent（内容创作者、数据分析师、投放优化师）
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** (52k⭐): 多 Agent 编排框架，适合构建营销活动团队（策划、创作、投放、分析角色分工）
- **[langgenius/dify](https://github.com/langgenius/dify)** (142k⭐): 无代码/低代码 Agent 构建平台，营销团队可快速搭建内容生成、客户服务等营销 Agent 工作流
- **[open-webui/open-webui](https://github.com/open-webui/open-webui)** (138k⭐): 自托管 AI Web UI，营销团队用于本地部署内容生成和营销自动化工具
- **[lobehub/lobe-chat](https://github.com/lobehub/lobe-chat)** (77k⭐): 开源 ChatGPT UI，支持多模型切换，营销团队用于内容创作和营销助手场景
- **[FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise)** (53k⭐): 拖放式 LLM 流程构建器，营销团队无需编码即可构建内容生成和营销自动化流程
- **[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)** (170k⭐): Hermes Agent 框架，支持营销场景中的自定义 Agent 开发和部署
- **[VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)** (23.1k⭐): Agent Skills 精选列表，含多个营销相关技能模板和最佳实践

## 实践指南

### 内容创作
- AI 文案撰写（博客、广告、产品描述）
- 多模态内容生成（图文、视频脚本）
- 品牌声音一致性管理
- 内容日历规划与排期
### 社交媒体管理
- 多平台内容发布与调度
- 社区互动与评论管理
- 短视频（TikTok/Reels/Shorts）策略
- 社交媒体舆情监控
### SEO/SEM 自动化
- 关键词研究与内容优化
- 技术 SEO 审计
- 搜索排名监控
- 竞品 SEO 分析
### 广告投放
- 程序化广告购买
- 多平台广告管理（Meta、Google、TikTok）
- A/B 测试自动化
- ROAS 优化与预算分配
### 邮件营销
- 个性化邮件序列
- 自动化触发器
- 邮件效果分析
- 列表细分与管理
### 营销数据分析
- 归因分析
- 客户旅程分析
- 营销漏斗优化
- ROI 预测与报告

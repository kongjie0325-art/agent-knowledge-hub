## 概述

Awesome List 是 GitHub 上独特的知识组织形式——由社区维护的、结构化的精选资源列表。在 AI/Agent 领域，Awesome List 是快速了解某个技术方向的最佳入口，通常由领域专家持续维护，收录该方向最优质的工具、论文、教程和资源。

Awesome List 的价值在于"策展"（Curation）：在信息爆炸的时代，它们帮助开发者过滤噪音，直达最有价值的项目。2026 年，AI 领域的 Awesome List 已经从简单的链接集合进化为包含评估基准、对比矩阵和入门指南的知识库。

## 关键概念

- **内容组织**: 分类目录 / 标签系统 / 难度分级
- **质量筛选**: Stars 阈值 / 活跃度检查 / 维护状态
- **覆盖范围**: 工具 / 论文 / 教程 / 数据集 / 课程
- **更新频率**: 日更 / 周更 / 月更 / 不定期
- **社区贡献**: PR 提交 / Issue 讨论 / 投票机制
- **深度**: 仅链接 / 含描述 / 含评测 / 含对比

## 核心发现

1. **Awesome LLM Apps 100+ 可运行应用**（111k+ Stars），含代码，学习 Agent 应用模式
2. **Awesome AI Agents 专注 Agent 领域**（28k+ Stars），分类清晰
3. **Awesome LLM 最全面历史列表**（26k+ Stars），LLM 全栈覆盖
4. **Awesome Agent Papers 学术导向**（2.7k+ Stars），含论文解读
5. **Awesome AI Agents 2026 聚焦最新趋势**（976 Stars），追踪 2026 年新项目

## 实践指南

### 选型决策树

```
目标？
├── 学习 Agent 应用开发
│   ├── 需要可运行代码 → Awesome LLM Apps（100+ 应用）
│   └── 需要工具发现 → Awesome AI Agents
├── 研究 Agent 学术前沿
│   └── Awesome Agent Papers（论文导向）
├── 全面了解 LLM/AI
│   └── Awesome LLM（最全面的历史列表）
├── 追踪 2026 年最新趋势
│   └── Awesome AI Agents 2026
└── 全面搜索资源
    └── Awesome AI Agents (Schwoebel)（1500+ 资源）
```

### 如何贡献

```bash
# 1. Fork 仓库
# 2. 添加项目到对应分类
# 3. 确保包含：项目名称、链接、简要描述
# 4. 提交 PR
```
